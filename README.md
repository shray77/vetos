# VetOS — лаунчер-хаб вет-экосистемы (Flutter)

Android-лаунчер: домашний экран с живым метео-тайлом THI и плитками шести
проектов вет-контура shray77. Нажимаешь Home — попадаешь в свою экосистему.

**applicationId:** `ru.shray77.vetos` · v0.3.1 · sideload-APK (debug-подпись)

## Скачать

- APK: <https://github.com/shray77/vetos/releases/latest> → `VetOS-v0.3.1-arm64-v8a.apk` (~25 МБ, split-per-ABI)
- Исходники — этот репозиторий; архивом — там же, в аттачах релиза.

## Что внутри

- **Домашний экран** — часы, метео-карточка (THI станции по умолчанию,
  температура/влажность/ветер/THIadj, статус-цвет по шкале стресса КРС,
  спарк-лайн прогноза на 24 ч с порогами 68/72), сетка из 6 плиток проектов.
- **Тап по метео-карточке — быстрый выбор станции/района** (Таганрог,
  Новочеркасск… — шит с поиском); долгий тап — полный радар.
- **Встроенный браузер веб-плиток** — без тулбара Chrome: домен, тонкая
  полоса прогресса, «в Chrome», перезагрузка; «назад» ходит по истории.
  VetLearn всегда в Chrome (GitLab-логины). Настройка «Браузер веб-плиток»
  в настройках: встроенный / Custom Tabs.
- **Плитки проектов** — веб-проекты открываются встроенным браузером или
  Chrome Custom Tabs; APK-проекты запускаются по package name; если APK
  не установлен — мягкий фолбэк на веб-страницу, статус-точка на плитке.
- **Живая лента экосистемы** (v0.3.0) — горизонтальная лента карточек
  под метео-тайлом, каждая тянута из git-среза данных проекта:
  «7 дней THI» (наследует станцию метео-тайла), «Вспышки · ВетКарта»
  (свежие вспышки Ростовской обл.), «Прогноз vs факт» (MAE THI),
  «Недельный дайджест». Тумблеры в настройках. Конвенция для новых
  проектов — [docs/vetos-feeds.md](docs/vetos-feeds.md): git — это бекенд.
- **Дровер** — все запускаемые приложения системы с поиском и иконками,
  переключатель «с системными / без». С v0.2.0 — без ANR: список и иконки
  собираются в рабочем потоке, иконки кэшируются и сжимаются до 72px.
- **Настройки** — станция метео-тайла (все 49 из latest.json), живая лента
  (тумблеры по карточкам), браузер плиток, интервал автообновления
  (10/20/30/60 мин), инфо о срезе CI.
- **Кнопка «назад» не закрывает лаунчер** (PopScope) — ведёт себя как дом.
  Жестовая навигация: edge-to-edge + прозрачные системные панели,
  enableOnBackInvokedCallback — жест «назад» и предиктивная анимация.

## Данные метео и лента

Тот же источник, что дашборд: `raw.githubusercontent.com/shray77/vet-meteo/main/data/latest.json`
+ `forecast.json` (срезы каждые ~19 мин, метроном CI). Ретраи 3×, автообновление
по интервалу, обновление при возврате на домашний экран, если срез протух.

Лента тянет те же git-срезы: `data/outlook.json`, `docs/data/outbreaks.json`,
`data/verify.json`, `data/weekly.json` — каждый фид независимо (упал один —
остальные живут). Схема конвенции и как подключить свой проект —
[docs/vetos-feeds.md](docs/vetos-feeds.md).

## Как собрать

```bash
flutter pub get
flutter build apk --release        # split-per-ABI: arm64-v8a + armeabi-v7a
# или явно один ABI (для Oppo A18 / Helio G35 — arm64-v8a):
flutter build apk --release --target-platform android-arm64
```

С v0.3.1 `build.gradle.kts` держит `splits.abi` включённым для ARM-вариантов:
arm64-v8a (Oppo A18 и все современные ARM-смартфоны) + armeabi-v7a (старые ARMv7).
x86_64 выпилен — лаунчер не нужен на эмуляторах в проде, минус ~20 МБ на APK.

Первая сборка на новой машине скачает NDK (~2 ГБ) — это норма.
**Сборка без NDK на слабой машине:** вместо 2 ГБ NDK можно положить
шимы в `ndk/<ver>/toolchains/llvm/prebuilt/linux-x86_64/bin/`
(`llvm-strip`, `llvm-objcopy`, `llvm-readelf` → multiarch GNU binutils:
`apt-get download binutils-multiarch && dpkg -x … multibin`; llvm-strip
должен переводить `-o OUT IN` в позиционные аргументы objcopy).
Без стриппинга .so APK раздувается до ~500 МБ. Нужен полный JDK 17+
(в песочницах бывает только JRE — тогда Temurin в ~/jdk и
`org.gradle.java.home` в gradle.properties).

Сборка проверена на Flutter 3.47.3 / Dart 3.13.3 / AGP 9.1 / Gradle 9.3 / JDK 21.

## Как сделать домашним экраном

1. Установить APK (разрешить «неизвестные источники»).
2. Нажать Home (квадратик/домой) → Android предложит выбрать лаунчер → **VetOS**.
3. Или: Настройки → Приложения по умолчанию → Домашнее приложение → VetOS.
4. Вернуть системный лаунчер — там же переключить обратно.

## Почему свой MethodChannel вместо плагинов

`device_apps` 2.2.0 (discontinued) не собирается с AGP 9/Gradle 9 (`jcenter()`
удалён), `android_intent_plus` для запуска по пакету не нужен — нативный мост
`vetos/apps` (android/.../MainActivity.kt, ~120 строк Kotlin) делает всё сам:
список приложений с иконками, проверку установки, запуск по пакету.
Видимость приложений — официальное исключение `<queries>` MAIN/LAUNCHER,
без `QUERY_ALL_PACKAGES`.
